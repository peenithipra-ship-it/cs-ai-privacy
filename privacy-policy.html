Privacy Policy

Extension: CS AI Order Information (version 1.4.1)
Last updated: November 6, 2026

1. About this extension

CS AI Order Information is an internal tool for Shopee customer support agents. It adds a side panel to the internal CS and admin pages the agent is already authorised to use, so the agent can look up merchant information, order delivery information, payment and refund information, and calculate shipping fees while handling a support case.

The extension is operated by [Company / team name]. Questions about this policy can be sent to [contact email].

2. Information the extension handles

CategoryWhatWhy
Agent identity The company email address of the Chrome profile the agent is signed in to (company domains only; other addresses are discarded). To identify the agent, check the agent against the team's approved-user list, handle access requests, and keep each agent's history separate.
Case references entered by the agent Store ID, Order ID, case ID, driver ID and menu or option names typed into the panel. To run the lookups the agent requests and to pre-fill the team's Google Form.
Information retrieved from internal systems Merchant details (store name, merchant ID, phone numbers, email, latitude/longitude, store size, GP rates), order delivery details (driver ID, order amount, coins, shipping fee, delivered count), payment and refund details, and menu names and prices. To display reference information to the agent for the case being handled and to calculate shipping fees.

The extension reads only pages the agent is already signed in to and authorised to view. It does not read browsing history, other websites, or the content of unrelated tabs.

3. How information is used and shared

  • Display and calculation. Retrieved information is shown to the agent in the side panel. The extension never contacts customers and never submits forms on the agent's behalf.
  • Internal AI assistant. Where the agent uses the assistant feature, lookup results and the agent's user ID are sent to the internal Smart Orchestrator service (smart.shopee.io) to produce an answer for the agent.
  • Access control. The agent's company email is checked against an approved-user list kept in a Google Sheet, and access requests are submitted to a Google Apps Script endpoint operated by the team.
  • No other sharing. Information is not sold, used for advertising, or shared with any other third party, and is not used for any purpose unrelated to the extension's single purpose of supporting the agent's case.

4. Data stored on the device

The extension uses chrome.storage.local on the agent's own device to store:

  • the most recent order and payment/refund lookup results, so they are still shown when the panel is reopened;
  • a temporary case ID and driver ID used to pre-fill the Google Form (removed immediately after the form is filled);
  • the agent's user ID (company email) and sign-in state.

This data stays in the browser and is removed when the extension is uninstalled or when the agent clears the extension's storage.

5. Security

All communication with internal systems takes place over HTTPS. Access to the extension requires approval, and the extension only operates on the Shopee internal domains and Google services listed in its permissions.

6. Permissions

The extension requests only the permissions it needs: scripting, tabs and windows (to open background pages and read the information the agent asks for), storage (local settings and recent results), alarms (to keep a lookup running until it finishes), notifications (to tell the agent a lookup has finished), and identity / identity.email (to identify the agent).

7. Your choices

An agent can stop all processing at any time by uninstalling the extension. To remove locally stored data, clear the extension's storage from the Chrome extensions page. Requests about data held in internal systems should be sent to [contact email].

8. Changes to this policy

If the extension's data practices change, this page will be updated and the "Last updated" date above will change.
